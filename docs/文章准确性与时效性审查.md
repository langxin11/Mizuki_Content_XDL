## 理论与建模错误

这些问题不是随时间过时，而是原式或解释本身不正确；已修正可明确推导的部分。

| 文章 | 问题 | 修正与成立范围 |
| --- | --- | --- |
| CMU 1 | 机械动力学加速度、RK4 权重与阶段、隐式中点和后向欧拉混淆 | 已修正公式与方法名称；不同积分方法仍需选步长和检查误差 |
| CMU 1 | 线性化稳定性条件没有区分实部为零 | 所有特征值实部严格负可得到局部结论；零实部时线性化不足以判定 |
| CMU 1 | 内点互补式维度错误；将残差叫 Jacobian、其导数叫 Hessian | 改为逐元素乘积 λ∘s=ρ1、残差 r 与 Jacobian Dr；ρ 必须趋向零 |
| CMU 1 | Log-domain KKT 的右下块符号和指数错误 | 应为 −diag(s)，而非 +diag(λ)；已用有限差分核对 |
| CMU 1 | 砖块接触力符号、列向量转置、松弛参数化不一致 | 统一 μ 为接触力、s 为间隙；模型忽略旋转/摩擦/反弹，不能泛化到一般碰撞 |
| CMU 2 | 双积分离散输入矩阵漏乘 B | Bd=(IΔt+AΔt²/2)B，维度是状态数乘输入数 |
| CMU 2 | Bellman 原理被解释为任意中途到达平衡点 | 实际指相同剩余问题中最优轨迹后缀仍最优；非唯一解不要求轨迹逐点相同 |
| CMU 2 | 把反馈抗扰效果归因于 Riccati 比 QP 更鲁棒 | 同一无约束 LQR 的两种求解等价；比较中真正不同的是开环与反馈 |
| CMU 2/3 | 非零目标与轨迹跟踪只写 −K(x−xref) | 非零平衡点需平衡输入；一般轨迹跟踪需前馈/仿射项和可行性处理 |
| CMU 2 | LQR 调参、截断输入后似乎保证约束与收敛 | 限幅改变闭环，仅能报告本次仿真；无限时域 Riccati 结论需可稳定性、可检测性等条件 |
| CMU 3 | 航天器平均角速度、状态乘子和输入单位；无人机力臂 | 统一 n=√(μ/a³)、米制参数、力与加速度缩放，以及 l/2 力臂 |
| CMU 3 | 预测输入末项索引、堆叠矩阵次序 | 按逐步动力学重新推导并数值核对；凸 MPC 不能直接替代任意非线性 MPC |
| CMU 3 | 跟踪代价线性项正负号、变量排序、1/2 因子 | 改为 J=zᵀWz−2cᵀz+const；OSQP 对应 P=2W、q=−2c。示例误差代价另含 1/2 |
| CMU 3 | OSQP 示例未定义 Nh/P，rob/prob 混用，初态右端为零 | 统一变量与终端权重、分块组装，每步写入 −Aδx0，检查求解状态。示例只有输入约束 |
| CMU 4 | shooting/collocation 被等同于直接/间接法；Hermite–Simpson 被笼统认为更好 | 更正分类；方法优劣依赖问题、误差和求解器 |
| CMU 4 | 前馈项定义和更新符号不一致；写入路径约束便认为普通 iLQR 已处理 | 统一负号定义；约束需单独的算法机制，不能自动满足 |
| CMU 4 | 跟踪公式从参考状态推进而非实际状态，控制数组维度用 nx | 改为实际状态与反馈输入推进；控制维度为 nu |
| CMU 4 | 平面无人机竖直加速度漏 g；节点距离约束被当成完全无碰撞保证 | 补重力；使用平方距离，明确非凸性、节点间检查及几何尺寸 |
| CMU 5 | 四元数实部与角速度混淆、缺少括号与矩阵、坐标约定不明 | 明确实部在前、机体角速度、机体到世界旋转，区分纯虚四元数与叉乘矩阵 |
| CMU 5 | QᵀQ 明显偏离 I 的日志似乎作为验证通过 | 明确这是失败的正交性检查；归一化不能代替动力学和精度验证 |

主要理论资料：[CMU 课程](https://optimalcontrol.ri.cmu.edu/lectures/)、[MIT LQR 讲义](https://underactuated.mit.edu/lqr.html)、[MIT 轨迹优化讲义](https://underactuated.mit.edu/trajopt.html)。公式的符号与维度同时按正文约定直接推导。
