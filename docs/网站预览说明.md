## 再次启动或更新

在内容仓库打开 PowerShell，运行：

```powershell
./scripts/Start-ShironePreview.ps1
```

这会复制最新文章、重新构建、生成搜索索引，再启动本地预览。若文章没有变化，只需启动已有产物：

```powershell
./scripts/Start-ShironePreview.ps1 -SkipBuild
```

端口被占用时先结束此前的预览服务。浏览器中刷新即可查看新构建。

`preview/` 是被 Git 忽略的本地生成目录。同步脚本会重建其中的文章、草稿提示、关于页和本轮调整的配置；请在内容仓库 `posts/` 中写作，不要在预览副本中编辑正文。

若本地预览目录已删除，先创建并进入 `preview/shirone/`，再运行 `npx.cmd --yes shirones@0.1.5 init`。新机器须有 Node.js 24 LTS 和可访问 npm、字体服务的网络环境。

- 生产构建成功，11 篇文章均生成页面；知乎迁入的 7 张图片均参与图片优化。
- Astro 配置检查：45 个文件，0 错误、0 警告、0 提示。
