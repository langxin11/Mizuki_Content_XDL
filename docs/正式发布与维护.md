# 正式发布与维护

更新日期：2026-10-04。正式发布地址：<https://langxin11.github.io/>。

## 维护方式

内容仓库 `langxin11/Mizuki_Content_XDL` 管理文章、图片、个人配置和主题依赖。发布仓库 `langxin11/langxin11.github.io` 的工作流读取内容仓库的确切提交，在 Node.js 24 下安装锁定依赖，依次检查、构建、生成搜索索引、验收，再部署到 Pages。文章只有这一份编辑源。

日常修改正文：`posts/`。修改外观：`site/shirones/config/`。修改关于页：`spec/about.md`。不在 `node_modules` 或生成内容中修改文件。

首次在 `site/` 执行 `pnpm install --frozen-lockfile`，随后 `pnpm dev` 启动本地预览。开发服务会监听文章、关于页和图片源目录；保存后同步生成副本。开发预览允许查看草稿，正式构建会过滤 `draft: true`。旧的 4321 端口预览也保留，草稿有明显提示。

## 自动发布

将预期修改提交并推送内容仓库 main 后，发布仓库每小时检查一次新提交。只有内容或发布配置变化时才构建；检查频率不是到账时限，GitHub 队列可能延迟。未引入额外的个人访问令牌或部署密钥。

立即发布可在干净的 main 分支运行 `./scripts/Publish-Shirone.ps1`；它推送已提交的内容并向已有 GitHub 登录申请工作流运行，不自动暂存未知文件。也可在发布仓库 Actions 中手动运行 `Publish Shirone notes` 并指定内容提交。

每次公开构建自动验收：文章数量与源稿一致；7 个旧文章地址均存在；所有文章图片有本地文件；无 KaTeX 错误；RSS、Atom 和站点地图使用正式地址；草稿未生成页面，也未进入订阅与地图。失败时保留上一次成功的网站。
