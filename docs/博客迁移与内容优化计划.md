## 内容组织与外观原则

建议先保留三个主要入口：**最优控制与机器人学、开发与排障、关于**。知乎迁入的文章按主题归类，在文末注明来源，不额外制造一套重复分类。

首页以文章标题、短摘要和日期为主；阅读页优先保证公式、代码、图片和目录清晰。配色、字体、文章宽度等集中配置，减少逐页修改。封面按需添加，不要求每篇笔记都制作封面。

CMU 系列的阅读顺序：动力学与优化基础 → LQR → MPC → 非线性轨迹优化 → 旋转与四元数。第 4 篇篇幅较长，后续可按“方法推导”和“作业实现”拆分，但须先完成旧链接映射。

## 笔记优化规则

1. 标题包含具体主题，摘要说明读者能解决什么问题。
2. 开头交代适用背景、先修知识和阅读路线。
3. 技术笔记按“问题 → 模型与假设 → 推导 → 实现 → 结果与局限”组织；故障记录按“环境 → 现象 → 处理经过 → 验证 → 未知项”组织。
4. 保留个人观察和失败经验；不把一次成功写成通用结论，不补造仿真结果。
5. 数学符号、状态维度、坐标系、单位和控制输入含义保持一致。
6. 长代码保留必要上下文；补全依赖与运行入口后，才标记为可复现。
7. 保留首发时间，使用 `updated` 记录实质修改日期。
8. 参考资料尽量链接课程、论文和官方文档；保留原有第三方参考，不把其内容表述为自己的原创。

## 知乎筛选与导入

优先迁入有完整推导、代码、实验结果、排障过程或独立分析的文章。点赞数只作辅助，不以热度代替质量。与本地 CMU 笔记重合的文章合并补充，避免发布两份近似内容。

每篇登记：原文标题、URL、首发日期、原更新时间、主题、推荐理由、重复情况、图片数量、待核查内容、目标文件和导入状态。未读取原文前不预填文章名称或迁移结论。

导入步骤：获取原文 → 保存来源信息 → 转换公式与代码 → 保存有权使用的图片并改为本地引用 → 补背景与小结 → 与现有文章去重 → 设置 `draft: true` → 预览后发布。作为回答迁入时，须补齐原问题背景，使文章可以独立阅读。
